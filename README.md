# Student Registration Form

## Project Description
Student Registration Form is a Windows Forms application developed using C# and .NET. It provides a simple form to collect student information and validates the entered details before submission.

The application allows users to enter personal details, select a gender and course, choose hobbies, and select their date of birth. After successful validation, all entered details are displayed in a summary.

## Features

- Enter student name using TextBox.
- Enter and validate email address.
- Select gender using RadioButton.
- Choose a course using ComboBox.
- Select multiple hobbies using CheckBox.
- Select date of birth using DateTimePicker.
- Validate empty fields before submission.
- Display error messages using MessageBox.
- Show a summary of student details after successful submission.

## Technologies Used

- C#
- .NET
- Windows Forms (WinForms)
- Visual Studio

## Validation

The application performs the following validations:

1. Student name cannot be empty.
2. Email address must be in a valid format.
3. Gender must be selected.
4. Course must be selected.
5. Required fields must be completed before submission.

If any validation fails, an error message is displayed using MessageBox.

## Project Objective

The main objective of this project is to understand Windows Forms controls, event handling, user input collection, form validation, and displaying data using C#.
